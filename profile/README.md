## 关于我们

**GDUF Community** 希望连接对技术与开源感兴趣的同学，把学习中的想法、研究中的探索和校园里的实际需求，变成可以阅读、使用和共同改进的项目。

从数学科普动画到校园服务界面，从数据分析到研究工具，我们关注具体问题，也重视解决问题的过程。我们希望通过公开代码、完善文档和交流实践经验，让更多人能够参与、理解并继续改进这些工作。

无论你来自哪个专业、是否有过开源经验，都欢迎从自己感兴趣的问题开始。

## 在这里，一起做些什么

- **把问题做成项目**：从校园需求、课程实践或研究问题出发，动手实现一个能用的工具。
- **把过程写成经验**：分享学习笔记、复现步骤和问题排查过程，让后来的人更容易开始。
- **在协作中学习**：通过 Issue 讨论想法，通过 Pull Request 改进代码、界面、文档与示例。

## 一起参与

开源贡献可以从一次试用、一条反馈，或一处文档修正开始。

1. **找到感兴趣的项目**：阅读仓库 README，了解项目范围、运行方式和贡献说明。
2. **交流问题与想法**：在对应项目的 Issues 中描述使用场景、复现步骤或改进建议；较大的改动先与维护者讨论。
3. **提交你的改进**：Fork 仓库，完成范围清晰的修改，通过 Pull Request 说明改动内容与验证结果。

有新项目想法，或希望参与社区共建？欢迎到 **[社区交流入口](https://github.com/gduf-community/.github/issues)** 发起 Issue，介绍你的想法与感兴趣的方向。
