## 关于我们

**GDUF Community** 是由广东金融学院学生发起的学术前沿技术社区。

我们关注数学、人工智能、算法、量化、前端与机器人等方向，也关注这些领域之间不断出现的交叉地带。

大学中的研究、竞赛、工程实践和个人探索，往往分散在不同专业、学院、实验室和小团队中。知识难以沉淀，项目难以延续，不同方向的人也很难发现彼此。

我们希望建立一个长期存在的技术协作网络，将分散的研究兴趣、工程能力和项目经验连接起来。

在这里，一个问题可以从数学开始，经过算法实现，被用于人工智能或量化研究，最终通过软件、Web 或机器人系统成为真正能够运行和使用的成果。

**我们希望打破方向之间的壁垒，让不同领域的人在这里相遇。**

## 研究方向

我们的方向不是彼此隔离的部门，而是一个可以自由交叉的技术网络。

### Mathematics · 数学

关注数学理论及其与计算、科学和工程之间的联系。

包括但不限于：

- 分析、代数、几何与概率
- 优化与数值计算
- 拓扑与拓扑数据分析
- 数学建模
- 数学软件与计算工具
- 数学与 AI、量化等方向的交叉研究

### Artificial Intelligence · 人工智能

关注现代人工智能系统及其基础方法。

包括但不限于：

- Machine Learning
- Deep Learning
- Large Language Models
- Agent Systems
- Multimodal Learning
- Scientific AI
- AI Infrastructure

我们不仅关注如何调用模型，也关注模型、算法、数据、系统和实际问题之间的关系。

### Algorithms · 算法

关注计算问题的结构、效率和工程实现。

包括但不限于：

- 数据结构与算法
- 图算法
- 优化算法
- 高性能计算
- 并行计算
- 算法工程
- 竞赛算法与理论计算

我们希望将算法从“题目”进一步推进到研究工具和真实系统。

### Quantitative Research · 量化

关注数学、统计、计算机科学与金融市场之间的交叉。

包括但不限于：

- Quantitative Research
- 时间序列分析
- 因子研究
- 市场数据分析
- 投资组合优化
- 风险建模
- 高频与低延迟系统
- Alternative Data

我们鼓励可复现研究、严格实验和对方法有效性的持续检验。

### Frontend & Product · 前端

关注现代 Web 技术、产品工程与人机交互。

包括但不限于：

- Web Development
- React / Next.js
- Data Visualization
- UI / UX
- Developer Tools
- AI Applications
- Scientific Visualization

前端并不只是界面层，它也是将研究、算法和技术真正交付给用户的重要环节。

### Robotics · 机器人

关注软件、算法、控制与物理世界之间的连接。

包括但不限于：

- Robotics
- Computer Vision
- SLAM
- Motion Planning
- Control
- Embedded Systems
- Autonomous Systems
- Embodied AI

机器人也是数学、算法、人工智能和工程实践高度交叉的方向。

## 交叉，而不是分割

真正有价值的问题通常不会严格属于某一个方向。

例如：

- **数学 × AI** —— 数学推理、Scientific AI、自动定理证明
- **数学 × 量化** —— 随机过程、优化、拓扑数据分析
- **算法 × 量化** —— 高频计算、低延迟系统、数据处理
- **AI × 机器人** —— 计算机视觉、具身智能、自主系统
- **AI × 前端** —— Agent 产品、智能交互、AI Applications
- **算法 × 机器人** —— 路径规划、SLAM、实时计算
- **数学 × 算法** —— 数值方法、计算几何、高性能科学计算

我们鼓励成员进入自己熟悉的方向，也鼓励跨越原有边界，与其他领域的人合作。

---


## 不只是项目

代码仓库只是社区成果的一部分。

我们希望逐步开展：

- **Reading Group** —— 阅读论文、教材与技术资料
- **Research** —— 围绕具体问题进行长期研究
- **Open Source** —— 参与和维护开源项目
- **Workshop** —— 分享工具、方法与实践经验
- **Engineering** —— 构建真正可以运行和使用的软件
- **Competition** —— 参与算法、AI、量化与工程竞赛
- **Discussion** —— 讨论尚未解决的问题和新的技术方向

一个项目可能结束，但知识、工具、经验和协作关系应该留下来。

## 我们重视

### Frontier

持续接触新的研究、技术和工具。

我们希望了解一个领域正在发生什么，而不只停留在已经成熟的知识体系中。

### Interdisciplinary

不同领域之间的边界并不是不可跨越的。

数学可以进入人工智能，算法可以进入金融，Web 可以成为科研工具，机器人可以同时连接控制、视觉与 AI。

### Open

公开代码、公开讨论、公开知识。

能够开放的成果尽可能开放，让其他人能够阅读、验证、使用并继续改进。

### Long-term

我们希望建设的是可以持续多年的技术共同体。

代码可以迭代，项目可以更替，成员也会毕业，但知识和社区应该继续存在。

## 加入我们

无论你来自哪个学院、哪个专业，只要你对某个方向真正感兴趣，都可以参与。

你不需要同时了解所有领域。

你可以从一个问题、一篇论文、一段代码、一个 Issue，甚至一个尚未成形的想法开始。

### 你可以

- 加入一个已有项目
- 提交 Issue 或 Pull Request
- 发起新的研究或工程项目
- 组织 Reading Group
- 分享自己的研究、工具和经验
- 寻找其他方向的合作者

### 发起项目

如果你有一个值得长期推进的想法，可以在社区中发起项目。

我们尤其欢迎：

- 有明确问题意识的研究项目
- 可以长期维护的开源工具
- 跨方向合作项目
- 面向真实需求的工程系统
- 对现有方法进行改进、复现或验证的工作

项目不需要一开始就成熟。

重要的是问题本身值得研究，并且有人愿意持续推进。

## 面向未来

我们希望 GDUF Community 最终成为一个连接不同技术方向的公共节点。

有人在这里第一次接触研究。

有人在这里找到合作者。

有人把课程中的一个想法做成真正的软件。

有人从数学进入 AI，从算法进入量化，从 Web 进入科研，从机器人进入更大的工程世界。

我们并不知道下一个重要的问题会来自哪里。

但我们希望，当它出现的时候，不同方向的人能够在这里找到彼此。
