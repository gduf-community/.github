## 关于我们

**GDUF Community** 是由广东金融学院学生发起的学术前沿技术社区。

我们关注数学、人工智能、算法、量化、前端与机器人等交叉方向：大学中的研究、竞赛、工程实践和个人探索，往往在不同专业、学院、实验室和小团队，这种分散化场景往往不利于知识沉淀，项目延续，并且不同方向的人也很难发现彼此。

我们希望建立一个长期存在的技术协作网络，将分散的研究兴趣、工程能力和项目经验连接起来。在这里，一个问题可以从数学开始，经过算法实现，被用于人工智能或量化研究，最终通过软件、Web 或机器人系统成为真正能够运行和使用的成果。

**我们希望打破方向之间的壁垒，让不同领域的人在这里相遇。**

## 不只是项目

代码仓库只是社区成果的一部分。

我们希望逐步开展：

- **Reading Group** —— 阅读论文、教材与技术资料
- **Research** —— 围绕具体问题进行长期研究
- **Open Source** —— 参与和维护开源项目
- **Workshop** —— 分享工具、方法与实践经验
- **Engineering** —— 构建真正可以运行和使用的软件
- **Competition** —— 参与算法、AI、量化与工程竞赛
- **Discussion** —— 讨论尚未解决的问题和新的技术方向

一个项目可能结束，但知识、工具、经验和协作关系应该留下来。

## 加入我们

无论你来自哪个学院、哪个专业，只要你对某个方向真正感兴趣，都可以参与。

你不需要同时了解所有领域。

你可以从一个问题、一篇论文、一段代码、一个 Issue，甚至一个尚未成形的想法开始。

### 你可以

- 加入一个已有项目
- 提交 Issue 或 Pull Request
- 发起新的研究或工程项目
- 组织 Reading Group
- 分享自己的研究、工具和经验
- 寻找其他方向的合作者

### 发起项目

如果你有一个值得长期推进的想法，可以在社区中发起项目。

我们尤其欢迎：

- 有明确问题意识的研究项目
- 可以长期维护的开源工具
- 跨方向合作项目
- 面向真实需求的工程系统
- 对现有方法进行改进、复现或验证的工作

重要的是问题本身值得研究，并且有人愿意持续推进。

## 面向未来

我们希望 GDUF Community 最终成为一个连接不同技术方向的公共节点。

有人在这里第一次接触研究；有人在这里找到合作者；有人把课程中的一个想法做成真正的软件。

有人从数学进入 AI，从算法进入量化，从 Web 进入科研，从机器人进入更大的工程世界。

我们并不知道下一个重要的问题会来自哪里。

但我们希望，当它出现的时候，不同方向的人能够在这里找到彼此。
