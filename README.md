# GDUF Community · 组织主页

本仓库是 [gduf-community](https://github.com/gduf-community) 的公开 `.github` 仓库，用于维护 GitHub 组织首页。

展示内容位于 **[profile/README.md](profile/README.md)**。根目录的 README 是维护说明，不是组织首页正文。

## 展示方式

将 `profile/README.md` 提交到 `gduf-community/.github` 的默认分支（当前为 `main`）后，GitHub 会在组织的 Overview 页面展示它。仓库需要保持公开；无需构建、GitHub Pages 或部署工作流。

## 内容维护

- 组织介绍、项目展示和参与入口统一修改 `profile/README.md`。
- 新增项目时，确认仓库已公开，并依据项目自身的 README 编写简介；项目范围和使用说明以对应仓库为准。
- 项目迁移、改名或停止维护时，同步更新展示内容和链接。
- 当前使用本仓库的 Issues 作为社区交流入口。若关闭 Issues，请同步替换主页中的联系链接。
- 如需增加官网、邮箱或社群入口，请使用已确认可公开的信息。
- 提交前预览 Markdown，并检查项目链接、图片和页内导航。此仓库只有展示文档，无需安装依赖或运行构建。

## 参考

内容结构参考了 [GDUF Quant Lab](https://github.com/GDUF-QUANTLAB) 的组织定位与项目索引，以及 [华科开放原子开源俱乐部](https://github.com/hust-open-atom-club) 的社区介绍与参与入口。

GitHub 的展示规则见 [自定义组织资料](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile)。
